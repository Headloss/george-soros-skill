# George Soros perspective · Cursor Agent Skill

A [Cursor Agent Skill](https://cursor.com/docs) that encodes a **Soros-style** lens: fallibility, reflexivity, open vs closed society, and separating real trends from popular misconceptions.

## Install

Copy this folder into your skills directory:

- **User-wide:** `~/.cursor/skills/george-soros-perspective/`
- **Project-only:** `<repo>/.cursor/skills/george-soros-perspective/`

Ensure `SKILL.md` stays at the root of that folder.

## Contents

| Path | Purpose |
|------|---------|
| `SKILL.md` | Skill definition and workflow |
| `references/research/` | Source notes used to build the skill |
| `scripts/` | Optional helpers for research pipeline |
